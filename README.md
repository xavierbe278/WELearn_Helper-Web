# Welearn Helper | Web

基于 **PHP + 原生 JavaScript** 的 WeLearn 高效学习 Web 控制台。本仓库是原系列项目的 Web 分支：核心执行逻辑参考上游 [Welearn_helper](https://github.com/YZBRH/Welearn_helper) 的更新版（v0.5dev / Web GUI 版），并针对浏览器环境重写调度、并发与界面。

**⚠️ 声明：本项目仅供编程学习与网络请求研究使用，严禁用于任何商业用途、代刷盈利或二次倒卖。使用本项目产生的任何后果及平台违规风险由使用者自行承担。**

## ✨ 核心特性

| 能力 | 说明 |
| --- | --- |
| 双登录方式 | 账号密码（SSO 加密登录）或直接注入 Cookie |
| 单元 / 小节选择 | 勾选单元后懒加载小节；只刷指定小节，或整个单元 |
| 精准完成度 | 固定正确率（0–99）或随机区间（如 70,100） |
| 学习时长 | 固定秒数或随机区间，按**真实时间**结算，切后台不中断 |
| 并发控制 | 时长任务可设置并发章节数（1–50，默认 10），错峰启动避免瞬时压力 |
| 登录提示 | 顶部导航中间显示登录成功 / 失败 / 账号密码错误，手机端自动换行 |
| 只补未完成 | 默认跳过已完成章节，避免无意义重复提交（可关闭） |
| 一键完成 | 不用填写参数，自动按正确率 96–100%、时长 480–580 秒依次完成 |
| 运行提示 | 大号倒计时采用翻页时钟，显示「本轮并发剩余 + 总计剩余」，未算出时显示正在计算；手机端置顶显示 |
| 登录记忆 | 非隐私浏览器 7 天内自动恢复登录与上次的单元选择；Cookie 失效或退出即清除 |
| 会话复用 | 切换“正确率 / 时长”模式无需重新登录；关闭后 7 天内重新打开自动恢复（非隐私模式） |
| 自动刷新 | 任务结束后自动重新读取课程与小节状态 |
| 实时日志 | 分级着色、自动滚动、一键导出 / 清空；失败信息同时显示在登录按钮下方 |
| 手机端日志 | 底部常驻日志条显示最新状态与停止按钮，点“展开”查看完整日志 |
| 完成弹窗 | 任务结束置顶显示完成内容、耗时和“有效时长（已提交）”，并提示时长数据需 1–15 分钟更新 |
| 停止结算 | 停止时提示“正在停止”，提交已等待的部分时长；完成弹窗显示有效时长 |
| 浅色 / 深色 | 默认浅色，右上角一键切换并记忆选择 |
| 响应式 | 手机、平板、电脑均可直接使用 |
| 安全代理 | `api.php` 只允许转发 `welearn.sflep.com` 与 `sso.sflep.com`，白名单内的 http 自动升级为 https |

## 🚀 部署

### 环境要求

- 任意支持 PHP 的 Web 服务器（Nginx / Apache / 虚拟主机均可）
- PHP **7.4+**，开启 `curl` 扩展
- 站点需支持 HTTPS（微信 / 部分浏览器对混合内容有限制，且 Cookie 涉及登录态）

### 步骤

1. 把上面的文件全部上传到网站目录（例如 `/www/wwwroot/welearn/`）。
2. 确认 `api.php` 可以被浏览器访问（同目录、同域名）。
3. 浏览器打开 `index.html` 即可使用。

> 本项目**不需要**数据库，也不需要 `data` 目录；服务端不保存账号、密码或 Cookie。

### Nginx 参考

```nginx
location ~ \.php$ {
    include        fastcgi_params;
    fastcgi_pass   unix:/run/php/php8.1-fpm.sock;
    fastcgi_param  SCRIPT_FILENAME $document_root$fastcgi_script_name;
}
```

如果使用 CDN / 反向代理，请确保 `POST /api.php` 不被缓存。

## 📖 使用

1. **登录**：输入手机号与密码，或粘贴 Cookie 后点击注入。
2. **选课程**：登录成功后自动加载课程列表。
3. **选单元**：勾选单元会自动加载小节；只勾部分小节就只刷这些小节。
4. **设参数**：
   - 正确率：`85` 表示固定 85%；`70,90` 表示 70%–90% 随机。
   - 时长：`60` 表示每章节 60 秒；`30,90` 表示 30–90 秒随机。
5. **开始任务**：运行中可随时“停止”；结束后自动刷新状态。
6. **一键完成**：不想调参时直接点“一键完成”，自动按正确率 96–100%、时长 480–580 秒跑完当前选择；未选单元时处理全部单元。运行条会显示已运行 / 本批剩余时间，时长任务每 60 秒在日志里报一次进度。

### 高级选项

- **并发章节数**：仅时长任务生效。数值越大完成越快（默认 10，最大 50），但过高可能被平台限流，建议 10–20。
- **仅处理未完成小节**：默认开启。关闭后会重新提交已完成章节（可用于覆盖历史成绩）。

## 🧭 常见问题

**登录提示“设备时间不准 / 触发风控”？**
登录参数包含客户端时间戳，请把系统时间校准到准确时间后重试。

**Cookie 失效？**
Cookie 有有效期，重新在浏览器登录 WeLearn 后复制最新 Cookie 即可。Cookie 保存在浏览器的 `localStorage`（最多 7 天），主动退出或 Cookie 失效即清除。

**某些章节一直失败？**
未开放章节会被跳过；若整单元失败，通常是会话过期或平台临时限制，稍后重试对应单元即可。

**任务运行中能关闭页面吗？**
不能。任务在浏览器里执行，关闭页面会中断；可以切到后台，时长任务仍按真实时间推进。

**为什么必须通过 `api.php` 代理，浏览器不能直接请求 WeLearn 吗？**
不能。WeLearn 返回 `Access-Control-Allow-Origin: *`，但没有 `Access-Control-Allow-Credentials`，登录 Cookie 又是 `SameSite=Lax`：跨域 `fetch` 带 Cookie 会被浏览器拦截，不带 Cookie 又拿不到登录态，`no-cors` 只能发不能读。所以纯网页必须走同源代理；若一定要用用户本机网络发请求，只能额外运行本地助手、浏览器扩展，或在 WeLearn 页面执行书签脚本（桌面端）。
